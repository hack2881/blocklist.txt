# AdGuard DoubleClick Blocklist

Deze lijst blokkeert advertenties en tracking van `doubleclick.net`.

## Hoe te gebruiken in AdGuard Home
1. Ga naar je AdGuard Home dashboard.
2. Klik op **Filters** -> **DNS-blokkeerlijsten**.
3. Klik op **Blokkeerlijst toevoegen** -> **Voeg een aangepaste lijst toe**.
4. Geef de lijst een naam (bijv. "DoubleClick Block").
5. Plak de **Raw** URL van je `blocklist.txt` bestand van GitHub in het URL-veld.
   * *Tip: Klik op GitHub op het bestand 'blocklist.txt' en druk rechtsboven op de knop **Raw** om de juiste link te krijgen.*
6. Klik op **Opslaan**.
